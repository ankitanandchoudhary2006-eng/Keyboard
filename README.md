# Keyboard

<img width="901" height="396" alt="Screenshot 2026-11-17 000537" src="https://github.com/user-attachments/assets/6cb96eb1-c60d-4b65-8bd9-a84dfccb951e" />

I made a custom 60% layout keyboard which has per swich diode for ghosting protection and it has hotswaps So that we can change the switches anytime as per our wich . The MCU is based on STM32F072CBT6 and we have designed the circuit using  a custom chip to save space (instread of a module). PCB was designed in Kicad and CAD was made in Fusion.

### Features
- Based on STM32F072CBT6 Chip
- Has 60% Compact layout
- uses diodes for ghosting prevention
